# 하라고지페 근무·급여

와인바 하라고지페의 주간 스케줄, 근무 가능 투표, 실제 근무 체크, 월 급여 계산, 급여명세서를 한 페이지에서 관리하는 도구.

- 주소: https://fastkorea12-png.github.io/haragojipe-pay/
- 기존 근무노트 관리자 비밀번호로 로그인합니다. 비밀번호는 저장하지 않으며 관리자 토큰과 만료 시각만 이 브라우저에 저장합니다. 상단 ‘잠그기’로 삭제할 수 있습니다.
- 데이터: 근무노트 Cloudflare Worker의 D1 `haragogipe-staff-shifts`, `pay_docs` 테이블에 저장합니다. 공개 저장소에는 직원·급여 데이터가 없습니다.
- 서버가 연결되지 않으면 오류 배너의 ‘다시 시도’를 누릅니다. 다른 기기의 변경은 창을 다시 열거나 60초마다 확인합니다.

## 계산 규칙
- 시간 표기: `6.5-1` = 18:30~다음날 01:00, `8-2`, `19:30-23:30` 모두 가능.
- 실제 근무 체크: 근무함 / 시간 다름(실제 시간 입력) / 결근. 급여는 체크 결과 기준, 미체크는 예정 시간.
- 야간가산·주휴수당·휴게시간 차감은 설정에서 켜고 끔 (5인 미만이라 기본 꺼짐).
- 공제: 없음 / 3.3% / 4대보험(요율은 설정에서 수정).

로컬 검수 방법은 `qa/README.md`.
